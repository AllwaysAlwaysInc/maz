Drop your Meshy-exported .glb 3D models into this folder using these exact filenames:

- character.glb   (Main Player Hero)
- bat.glb         (Bat Familiar)
- hound.glb       (Hound / Dog Familiar)
- dragon.glb      (Dragon Familiar)
- owl.glb         (Owl Familiar)
- sabertooth.glb  (Sabertooth Familiar)
- serpent.glb     (Serpent / Snake Familiar)

MandalOz 3D automatically loads any .glb found here with PBR lighting, auto-scaling, and animation playback, and falls back to the built-in 3D models for any file not yet added.
